An out-of-office auto-reply written as if a houseplant sent it, for make.fun's "The Houseplant Out-of-Office" bounty: one line, 120 characters at most, from the fern that has been ignored by the same window since March.

## The line

> Out of office: I have been by this window since March. Water me, and I will pretend this reply was prompt. — The Fern

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It reads as a genuine out-of-office reply in the plant's own voice, and the joke grows out of the plant's life — months by the window, no water, no attention — rather than decorating it. The punch is a small bargain: care for me and I will forgive the delay. Tight and original, with no worn office cliches.
